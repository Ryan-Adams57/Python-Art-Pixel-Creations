# Python Art & Pixel Creations

A playful collection of Python scripts that draw **pixel art, characters, animations, and themed graphics** on screen, from cute characters and flowers to holiday icons and heart patterns. It's a fun sandbox for creative coding and visual experimentation in Python.

## What's inside

The repo is packed with standalone drawing scripts, each producing its own piece of art. You'll find things like:

- **Characters** such as `Batman.py`, `Hello_Kitty.py`, `Kirby.py`, `Doraemon.py`, and `Bugs_Bunny.py`.
- **Cute & seasonal designs** like flowers (`Flor_Minecraft.py`), hearts (`Corazon_pixel.py`), a dinosaur (`Dino.py`), and holiday-themed pieces.
- **Numbers, logos, and fun icons** like `2024.py`, `2025.py`, and `Duolingo.py`.

Each file is self-contained, so you can run any one on its own to see its artwork come to life.

## How it works

The scripts use Python's built-in **`turtle`** graphics module to draw shapes, patterns, and pixel-style images in a graphics window. Because `turtle` ships with Python, there's nothing extra to install.

## Getting started

### What you'll need

- **Python 3.x** installed on your computer.
- That's it! The `turtle` module comes bundled with Python.

### Run a drawing

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run any script with Python. For example:

   ```bash
   python3 Dino.py
   ```

4. A window will open and draw the artwork in front of you. Try another file for a different creation!

> **Tip:** If a filename contains spaces (for example `Flor Amarilla 2.py`), wrap it in quotes: `python3 "Flor Amarilla 2.py"`.

## Explore & experiment

Each script is a great starting point for tinkering. Open one up and try changing the colors, sizes, or coordinates to make the art your own, or use the code as a reference for building your own `turtle` drawings from scratch.
